# 许愿星计划 - 需求说明书

## 1. 项目背景与目的

### 1.1 项目背景

本计划针对容易拖延、觉得任务难度大、不想做相关情况的人群。通过将工作和学习任务变成好玩的游戏，建立成就感，让用户能够从小事上获取成就感，愿意甚至期待去工作和学习。

### 1.2 项目目的

1. **降低启动门槛**：通过即时奖励，让“来自习室”这个动作本身变得有吸引力。
2. **重建“工作=好事”的神经连接**：用高频、即时的正向反馈，训练杏仁核，让它逐渐把工作与愉悦感联系起来。
3. **提供可持续的动力**：通过游戏化设计（随机奖励、可视化进度），让长期坚持变得有趣。
4. **恢复自我效能感**：通过一次次“我做到了”的微小胜利，重建对自己的信任。

## 2. 功能需求

### 2.1 任务设置功能


- 能够设置任务名称
- 能够设置完成一次任务兑换许愿星的比例
- 能够设置任务的完成次数：
  - 可以限制完成多少次后就结束
  - 也可以不限制完成次数
- 能够设置完成单次任务可以兑换的奖励
- 奖励兑换方式包括：
  - 兑换许愿星
  - 兑换半价抽卡次数
  - 兑换抽卡次数
- 提供便捷的任务设置入口

### 2.2 每日记录功能

- 记录每日获得的许愿星数量
- 记录消耗许愿星进行抽卡的情况
- **单次任务记录**：也可以直接填入一个新的任务，并且马上把这个任务完成（不预先设置任务，直接记录并获得奖励）

### 2.3 骰子功能

- 当日满足五颗星星时，可以额外扔一次骰子
- 根据骰子的点数获得对应的星星

### 2.4 核心愿望（奖池）功能

- 能够录入核心愿望（作为奖池），核心愿望可以选择是否上传图片
- 能够输入每个愿望需要抽到多少次才能合成一个完整的愿望

### 2.5 抽卡功能

- 能够消耗星星进行抽卡
- 能够消耗已有的抽卡次数进行抽卡（包括全价抽卡次数和半价抽卡次数）
- 抽卡后更新合成进度

### 2.6 统计展示功能

- 显示星星累积数量，以及剩余的星星数量
- 能够看到每天星星的数量展示
- 能够分别看到早、中、晚的星星数量（与每日记录的时间戳挂钩，根据完成记录的时间自动判定是早上、中午还是下午）
- 按天数查看许愿星数量及流水
- 10个大星星换成1个漂亮的宝石
- 能看到累积星星的数量

### 2.7 许愿星兑换愿望

- 用于购买自己喜欢但平时觉得没啥必要的东西
- 作为给自己的一些小动力

### 2.8 周末加倍机制

- 周六和周日，所有获得的星星数量翻倍
