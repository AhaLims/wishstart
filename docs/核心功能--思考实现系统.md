# 核心功能\-\-思考实现系统

1. 首页：每日记录，记录今天工作的时间（按多少h多少min的方式记录），今天获得了多少颗星星，今天掷骰子的数量，还有快捷操作，包括了去工作（进入到工作时间页面），完成任务，快速记录，掷骰子，抽卡。

3. 工作时间页面：可以设置正计时or倒计时。正计时可以点击直接开始，并显示当前正计时的工作时间是多少，点击结束即可结束。倒计时需要先输入工作倒计时的分钟数，点击就开始倒计时，倒计时结束了会提醒，也可以中途点击停止。需要统计当日的工作总时间，是正计时的时间数量 + 倒计时时间实际完成的时间数量。这个与下面的时间型任务完成情况是挂钩的

2. 任务页面：
添加任务功能：任务包括两类，一种是通用型任务，另一种是时间型任务。
通用型任务：输入任务名称，限制完成次数（0或者不填就代表不限制），奖励（单选，星星or半价抽卡or免费抽卡，半价抽卡or免费抽卡都是默认只能一次的），如果奖励选择是星星，还需要填写完成一次获得的星星数量。半价抽卡是花费3颗星星抽一次奖
时间型任务：属性跟上面的通用型任务是一样的。不同的地方在于，这个任务的完成情况跟工作时间是挂钩的，还需要输入一个数字，代表"工作了多少分钟就会自动完成一次时间型任务",所以这个时间型任务的完成情况跟工作时间自动挂钩，自动会完成的。（比如我设置一个25min的时间型任务，我通过正计时完成了50min工作，那么久相当于自动完成了2个25min的时间型任务，并且自动获得两倍的星星数量）。这个时间型任务跟当日的工作时间有关。

显示当前所有的任务，并且展示任务信息，每个任务有完成和删除按钮，点击完成按钮就会显示完成了什么任务，获得了什么东西（如果是星星就显示获得了多少颗星星，如果是半价抽卡就显示获得了免一次半价抽卡，如果是免费抽卡就显示获得了一次免费抽卡）

3. 记录页面：显示今日总星星数，早上/下午/晚上分别获得的星星数量（都按照北京时间，早上是指6点到13点，下午是指13-18点，晚上是18-24点）。并且显示星星记录的明细

4. 扔骰子页面：要能扔骰子：扔骰子的规则为 当日满足五颗星星，可以额外扔一次骰子，根据点数（1到6的一个随机数）获得对应的星星。
也可以选择线下扔骰子并记录：线下掷骰子记录，如果你在线下掷了骰子，可以在这里记录并消耗1次掷骰子次数。输入点数并且记录之后也会消耗一次扔骰子的次数，并获得对应的星星数量。

5. 愿望页面：要能录入核心愿望（作为奖池），并且能输入愿望需要抽到多少次（也就是多少个碎片）才能合成一个完整的愿望

录入核心愿望的信息：包括愿望名称，图标，需要的碎片数量，当前已有碎片数量。

愿望页面包括两类愿望：收集中以及已完成愿望。
收集中的愿望以卡片的方式呈现，会显示收集中愿望的图标，需要多少碎片才能合成以及当前进度是多少，并且会显示状态（收集中or已集满的状态），还有有编辑和删除的功能。编辑按钮可以点击编辑愿望的信息。对于已经集满的愿望，点击合成愿望这个愿望的状态就会进入"已完成"状态，并且转而在已完成愿望栏显示
已完成愿望：对于状态为已集满的愿望，显示图标，愿望名称，显示"已完成"的状态，显示删除按钮（点击就从已完成栏删除）

5. 要能消耗星星抽卡，并且更新抽卡合成进度。抽卡有三种方式：花费五颗星星抽一次卡/花费半价抽卡次数 + 3颗星星抽一次卡 / 使用免费抽卡次数抽卡

抽卡页面需要显示当前可用星星，免费抽卡次数以及半价抽卡次数。并且可以选择使用上述三种方式中的哪种进行抽卡（免费抽卡/全价抽卡/半价抽卡）。

选择了抽卡方式之后，可以线上抽卡（会从还没集齐碎片的愿望中随机抽一个）；也可以选择对线下的抽卡进行记录（如果在线下抽了卡，可以在这里记录，会使用上方选择的消耗方式），这里可以选择愿望并且记录抽卡（默认是加一个碎片）

6. 统计功能：
- 统计累计星星数量，掷骰子数量，已完成愿望数量
- 显示星星的流水记录：什么时间完成了什么任务，获得了多少星星。或者是抽卡消耗了多少星星，获得了什么的碎片。
