# 核心功能\-\-思考实现系统

1. 要有每日记录，记录获得了多少许愿星，以及消耗许愿星抽卡的情况\-\-\>并且要有明确的流水

2. 要有能设置的名称，以及完成单次任务可以兑换的奖励（兑换许愿星/兑换半价抽卡次数/兑换抽卡次数）的点击完成按钮。最好能方便快捷设置任务？

3. 要能扔骰子：当日满足五颗星星，可以额外扔一次骰子，根据点数获得对应的星星

4. 要能录入核心愿望（作为奖池），并且能输入愿望需要抽到多少次才能合成一个完整的愿望

5. 要能消耗星星抽卡，并且更新抽卡合成进度

6. 其他小功能：（偏展示的部分）

    1. 能看到每天星星的数量展示，能分别看到早中晚的星星\-\-\-\>统计功能（按天数查看许愿星数量/流水）

    2. 10个大星星换成1个漂亮的宝石？。能看到累积星星的数量
